# Epic Survivor

Prototipo 0.1 de supervivencia 2D para iOS y Android, desarrollado con Godot 4 y GDScript.

## Estado

Repositorio inicializado. La implementación comienza por la base móvil vertical y el movimiento táctil de Aldric.

## Plan técnico

El plan completo de implementación, arquitectura, backlog y criterios de aceptación se añadirá en `docs/PLAN_TECNICO_PROTO_01.md`.

## Requisitos

- Godot 4.7.2 estable y sus plantillas de exportación coincidentes.
- Xcode en macOS para exportar iOS.
- OpenJDK 17 y Android SDK para exportar Android.

El alcance y las versiones de las herramientas se detallan en el plan técnico.
